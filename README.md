## What it does

`main.py` (Python standard library only) writes one original joke about Monday mornings to `/output/entry.txt`. The joke is deterministic — the same bytes on every run.

> Sunday night I set three alarms for Monday morning. By 6 a.m. they'd formed a union, voted unanimously, and gone on strike together.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
